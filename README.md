A Python implementation of a zoo management system developed as a final academic project. The objective is to manage animals, employees, enclosures and daily activities through a fully modular terminal application.

**Note:** The program interface is in **English(US)**.

## Features
• Multiple animal species with unique feeding rules **(Lion, Elephant, Monkey, Giraffe, Penguin)**\
• Employee management **(Zookeeper and Veterinarian)**\
• Enclosure system with species compatibility checking\
• Activity logging with timestamps\
• Backend and frontend architecture separation\
• Input validation\
• ASCII terminal interface\
• Menu navigation system.

## Run
```bash
> python __main__.py
```

### How to Use
Navigate through the main menu using the number of the desired option:
```bash
> 1
> 3
> 5
```
Each option redirects to a submenu **(animals, employees, enclosures, animal care or activities)**, where you can register, list, view details or delete records.

**Follow the on-screen prompts to enter IDs, names and other required information.**
